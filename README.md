# 貝斯和弦記憶 (BassChord)

依據上課筆記（音高、三和弦、指型）製作的貝斯和弦記憶 App。純靜態網頁，無需建置。

## 功能
- **音高**：音名 / 簡譜 / 唱名對照，點擊試聽，附口訣。
- **三和弦**：任一大調（12 調）的順階和弦、口訣（C 大調）、大小減判斷；可「遮住」欄位自我測試。
- **指板**：A 弦上的大調音階，以及各級和弦的指型與建議指法（食/中/無/小），可試聽。
- **測驗**：級數→和弦、和弦→組成音、大小減、口訣→和弦、指型辨識、指板找根音、音名簡譜唱名；答錯的題目更常出現（間隔重複），進度存於瀏覽器。
- **筆記**：原始 4 頁筆記。
- 可離線使用（PWA），可「加入主畫面」。

## 執行
```
python3 -m http.server 8000   # 然後開啟 http://localhost:8000
```

## 部署
由 Vercel 從 `main` 分支自動部署（純靜態，無需建置）。
